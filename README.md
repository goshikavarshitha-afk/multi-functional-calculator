# ⚡ Multi-Functional Calculator

A full-stack web-based calculator application built using **Java SE, Java Math, HTML5, CSS3, and Vanilla JavaScript**.

The application provides multiple mathematical utilities through a modern, responsive dashboard and can be accessed online through a public web URL.

## 🌐 Live Website

https://multifunctional-calculator.onrender.com/

---

## 📌 Project Overview

The Multi-Functional Calculator is designed to provide different types of mathematical calculations in one easy-to-use web application.

Instead of using separate websites or applications for different calculations, users can access multiple calculator functions from a single dashboard.

The application combines:

- Java SE backend
- Java Math operations
- HTML5
- CSS3
- Vanilla JavaScript
- Responsive web design
- Docker deployment
- Render cloud deployment

---

## ✨ Features

### ➕ Basic Calculator

Performs common two-number arithmetic operations:

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Modulus (%)

### 🧮 Advanced Calculator

Provides advanced mathematical operations such as:

- Square (x²)
- Cube (x³)
- Square Root (√x)
- Power (xʸ)
- Percentage
- Sine (sin)
- Cosine (cos)
- Tangent (tan)
- Logarithm (log)
- Absolute Value

### 🔢 Number Utilities

The project is designed to support additional number-related mathematical utilities.

### 📏 Unit Converter

The application can be extended with conversions between commonly used units.

Examples include:

- Temperature
- Length
- Weight
- Distance

### 🎂 Age Calculator

Calculates age based on the user's date of birth.

### 📜 History

Provides a section for maintaining and displaying previous calculator operations.

---

## 🖥️ User Interface

The application contains a dashboard-style interface with navigation sections for:

- Basic Calculator
- Advanced Calculator
- Number Utilities
- Unit Converter
- Age Calculator
- History

The interface is designed to be simple, responsive, and easy to use on different screen sizes.
